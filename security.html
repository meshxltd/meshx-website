Security

MeshX Software Ltd takes the security of our users, their data, and our systems seriously.

Our practices

We maintain a formal Information Security Policy that is reviewed every six months and covers:

  • Network security via Cloudflare (WAF, DDoS mitigation, TLS enforcement)
  • Endpoint protection with anti-malware and full-disk encryption
  • Multi-factor authentication on all critical systems
  • Role-based access control and least-privilege principles
  • Data classification and encryption (in transit and at rest)
  • Incident response and data breach notification procedures
  • Vulnerability and dependency management

Reporting a vulnerability

If you believe you have found a security issue affecting meshx.uk or MeshX services, please email:

security@meshx.uk

  • Describe the issue clearly and include steps to reproduce if possible.
  • Do not access, modify, or exfiltrate data that does not belong to you.
  • Give us reasonable time to investigate before public disclosure.

If you need encrypted email, ask at the same address and we will share a suitable option if available.

Other security and compliance enquiries

For questionnaires or vendor assessments: compliance@meshx.uk
